# Air Control
Perform common actions with hand gestures to improve productivity.

Air Control is an experimental project that helps you perform selected computer actions through hand movements captured by a webcam.  
Everything runs locally — no cloud services or external servers. It uses computer vision and gesture recognition to detect your hand movements and translate them into real-time actions.  
You can **remap gestures** to act as **keyboard shortcuts or mouse actions**, making certain tasks quicker and improving overall workflow efficiency.

## Current Status
The project is currently in the **testing phase** and not yet ready for regular use.  
Some features are experimental and under active development.

## Main Goals
- Local hand-tracking with OpenCV and MediaPipe  
- Fully offline processing  
- Custom gesture remapping to keyboard or mouse actions  
- Lightweight and privacy-friendly

## Future Plans
- Add more gesture types and presets  
- Improve recognition accuracy  
- Create a simple interface for gesture setup and customization
